## Found
- No accepted spec defined an end-of-day surface; every rule was derived from an owner instead of invented.
- Nothing could count what a study day recorded; `countTruth` is a recorded port refinement that writes nothing.
- E20 survived because a second guard masked the first; the T2 check now asserts each refusal names its own rule.

## Durable decisions
The end of a day is a boundary in time, not a verdict. The day is the study day a row recorded. A new day starts empty and nothing crosses the boundary. Counts are labelled inventory and are not progress. A change is claimed only when a canonical engine reported one. An unreadable count is named, never zero. An empty day is neutral; gaps are not drawn. No new surface, no chart, no grid.

## Key tensions resolved
1. **The one screen where a scoreboard is easiest to smuggle in.** Every forbidden thing is a missing field, not a rule to remember.
2. **Three plausible definitions of "a day".** Only the recorded study day survives travel and daylight saving.
3. **The only data that exists is activity.** It is shown as inventory and explicitly not as progress.
4. **A failed read looks like a zero.** It is named instead.
